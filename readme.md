# Interactive 3D Book Demo

This demo renders a layered, 3D-styled book that tilts toward your cursor and subtly fans its pages using CSS transforms and a small amount of JavaScript.

## Usage

1. Open `index.html` in a modern browser (no build step required).
2. Move your mouse across the book to tilt the cover and pages; move away to reset.
3. Adjust sizing or colors via the CSS variables at the top of the `<style>` block if desired.

## Files

- `index.html` – Standalone page containing the HTML, CSS, and JavaScript for the interactive book.
